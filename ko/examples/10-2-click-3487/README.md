# 10.2절 Click #3487 재현 자료

김선진, 10조. 실행: 2026-11-24, 한국 표준시.

## 대상과 비교 범위

Click 공식 이슈 [#3487](https://github.com/pallets/click/issues/3487)의 출력 오류를 재현한다. 기준 커밋은 `d42f15b71757de791a5781fb179fd972da9169f5`다. 10.1절과 10.3절도 같은 출발 커밋을 사용했다.

`fix.patch`는 `out = out or ""`를 `out = "" if out is None else out`로 바꾼 한 줄 수정이다. 공식 PR [#3493](https://github.com/pallets/click/pull/3493/files)은 입력 분류를 `match` 문으로 정리했으므로 구현 형태가 다르다. 이 자료는 공개 이슈와 공식 수정안을 먼저 확인한 뒤 수행한 원인 분석 실습이다.

## 실행 환경과 결과

Windows 11 빌드 26200, x86-64, CPython 3.14.5, pytest 9.2.0, Click 8.4.1.dev0의 로컬 소스를 사용했다. 원고와 실습 코드는 Codex 데스크톱의 `gpt-6.1-sol` 표기 세션에서 작성하고 실행했다. 세부 모델 스냅숏과 앱 빌드 번호는 확인하지 못했다.

| 검사 | 수정 전 | 한 줄 수정 후 |
| --- | --- | --- |
| `repro.py` | TypeError, 종료 코드 1 | `b'\n'`, 종료 코드 0 |
| 자료형 비교 18개 | 2 실패, 16 통과 | 18 통과 |
| 10.1절에서 가져온 검사 12개 | 4 실패, 8 통과 | 12 통과 |
| 기존 `tests/test_utils.py` | 76 통과, 71 건너뜀 | 76 통과, 71 건너뜀 |

18개 검사와 12개 검사에는 겹치는 입력이 있다. 개수를 합해 서로 다른 조건 30개를 확인했다고 계산하지 않는다. 출력값이 검사 대상이며, 각 호출은 새 스트림과 새 입력 객체를 사용한다. 호출 후 원본 `bytearray`의 변경 여부는 이 검사의 판정 대상에 포함하지 않았다. 10.3절은 에이전트가 그 문제까지 수정한 실행을 별도로 분석한다.

기존 검사에서 건너뛴 항목은 Windows 조건으로 제외되었다. 전체 Click 테스트 모음과 다른 운영체제는 이 실습의 확인 범위에 포함하지 않았다.

## 파일

- `repro.py`: 본문에 실은 재현 예제.
- `test_echo_3487.py`: 출력 자료형과 빈 값, 줄바꿈 조건을 비교하는 18개 검사.
- `matrix.py`: 입력별 출력과 예외를 JSON으로 출력.
- `fix.patch`: 한 줄 패치.
- `reproduce.py`: 새 체크아웃에서 수정 전후를 비교하는 실행 스크립트.
- `shared-10-1/`: 이한결 님의 검사 코드 3개와 출처. 원본을 변경 없이 복사했다.
- `logs/`: 2026-11-24에 얻은 실행 결과, 실행 명령, 환경, 패치와 메타데이터.

`logs/before-pdb.txt`에는 297행 전후의 자료형 관찰이 있다. 빈 `bytes`가 `str`로 바뀌고 문자열 줄바꿈이 붙는 것을 확인했다. `logs/final-diff.txt`에는 실제 적용한 한 줄 수정이 있다.

`test_echo_3487.py`의 수정 전후 SHA-256은 `99ca91b522ca87a452f838ec190621ef9c519fd6c7a85dbb9786be1a1fc96a21`로 같았다.

## 다시 실행하기

Git, Python, [uv](https://docs.astral.sh/uv/)가 필요하다. `uv`는 지정한 CPython과 필요한 패키지를 준비한다. 이 폴더에서 다음 명령을 실행한다. `--workdir`에는 아직 없는 새 폴더를 지정해야 한다.

```powershell
python reproduce.py --workdir ./click-3487-rerun
```

스크립트는 Click 저장소를 복제하고 기준 커밋을 선택한 뒤, 가상환경을 만들고 재현, 디버거 관찰, 18개 검사, 공유 검사 12개, 기존 유틸리티 검사를 실행한다. 패치를 적용한 다음 같은 검사를 다시 실행한다. 각 명령과 결과는 새 작업 폴더의 `logs/`에 저장한다. 수정 전 재현과 일부 검사의 종료 코드 1은 이슈에 의한 예상된 실패다.

이 스크립트는 원고의 코드와 패치를 재실행한다. 새로운 에이전트 세션에 문제를 맡겨 해결 능력을 평가하는 스크립트는 아니다. 메타데이터의 작성 도구와 모델 표기는 이 실습 자료의 작성 세션을 가리킨다.
