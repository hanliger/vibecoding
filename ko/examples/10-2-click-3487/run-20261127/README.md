# 10.2절의 2026-11-27 실행 자료

김선진, 10조. 기말발표 PPT와 에이전트 협업 중심 개정 원고에 사용한 실행 자료다.

## 실행의 성격

Codex 세션이 공개 이슈와 수정 방법을 알고 시작한 재현 실습이다. 독립 에이전트의 해결률을 측정한 평가가 아니다. 원고의 요청문은 교육용 예시이며 실제 사용자 발언을 옮긴 대화록이 아니다. 원고의 관찰값과 검사 결과는 이 폴더의 실제 도구 실행 출력에 근거한다.

기준 소스는 pallets/click의 `d42f15b71757de791a5781fb179fd972da9169f5`다. 별도 체크아웃에서 수정 전 실행, pdb 관찰, 한 줄 패치 적용, 수정 후 실행을 순서대로 수행했다. 기존 가상환경의 Python을 사용하되, 환경 변수 `PYTHONPATH`를 새 체크아웃의 `src`로 지정했다. `environment.txt`에서 실제 import 위치를 확인했다.

## 실행 조건

- 실행일: 2026-11-27, 한국 시각.
- 도구: Codex 데스크톱. 기록의 모델 표기: `gpt-6-astra`. 세부 모델 스냅숏과 앱 빌드는 미확인.
- Windows 11 빌드 26200, CPython 3.14.5, pytest 9.2.0, 기준 소스의 Click 버전 8.4.1.dev0.
- 패치 전후 각 1회 실행. 검사는 동일한 파일을 사용했다.

`before-matrix.txt`와 `after-matrix.txt`는 입력별 관찰이다. `pdb-observation.txt`는 297행 실행 전후 자료형을 보여 준다. `final-diff.txt`는 실제 한 줄 패치다. 공식 병합 PR #3493의 match 문 변경과는 다르다.

모든 로그는 `logs/`에 있다. `reproduce-metadata.json`, `observe-metadata.json`, `verify-metadata.json`에는 실제 명령, 표준 입력, 종료 코드, 실행 시각과 검사 파일 해시가 있다. `test_echo_3487.py`의 수정 전후 SHA-256은 `99ca91b522ca87a452f838ec190621ef9c519fd6c7a85dbb9786be1a1fc96a21`로 같다.

## 코드와 다시 확인할 때의 주의점

`repro.py`, `matrix.py`, `test_echo_3487.py`는 실행한 파일 그대로다. `session.py`는 당시 명령을 실행한 보조 스크립트로, 작업 폴더와 가상환경의 상대 위치에 의존한다. 이 배포 폴더로 옮긴 뒤 그대로 실행하는 이식 가능한 설치 스크립트는 아니다. 당시 사용한 경로는 메타데이터에서 확인할 수 있다. 이 파일은 자동으로 새 에이전트 세션을 시작하지 않는다.

독자가 실행 환경을 새로 구성하는 방법은 [상위 폴더의 재현 안내](../README.md#다시-실행하기)에 있다. 그 자동 재실행 스크립트는 11월 24일 자료의 구성으로 공유 검사 12개까지 실행하므로, 이 폴더의 11월 27일 결과와 실행 범위를 구별한다. 11월 27일에는 10.1절의 12개 검사를 다시 실행하지 않았다.

전체 Click 검사와 다른 운영체제는 실행하지 않았고, 71개 건너뜀은 Windows 조건 제외다. 원본 bytearray 객체의 호출 후 변경 여부는 출력 검사의 판정 범위에 포함하지 않았다. 요청문별 효과와 작업 시간의 개선은 측정하지 않았다.
